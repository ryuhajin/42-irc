# 커맨드별 성공 메시지 및 오류 메시지

## NICK 커맨드

### 성공 메시지

| 번호 코드 | 메시지                                                                                   | 설명                                     |
|-----------|------------------------------------------------------------------------------------------|------------------------------------------|
| 001       | `:Welcome to the Internet Relay Network <nick>!<user>@<host>`                            | 서버에 성공적으로 연결되었을 때 표시됩니다. |
| 002       | `:Your host is <servername>, running version <version>`                                  | 서버 정보 및 버전을 알려줍니다.           |
| 003       | `:This server was created <date>`                                                        | 서버의 생성 날짜를 알려줍니다.            |
| 004       | `<servername> <version> <available user modes> <available channel modes>`                | 지원되는 사용자 및 채널 모드 정보를 제공합니다. |

### 오류 메시지

| 번호 코드 | 메시지                                           | 오류 발생 이유                                        |
|-----------|--------------------------------------------------|-------------------------------------------------------|
| 431       | `:No nickname given`                             | 닉네임을 제공하지 않았을 때 발생합니다.                |
| 432       | `<nick> :Erroneous nickname`                     | 잘못된 형식의 닉네임을 사용했을 때 발생합니다.         |
| 433       | `<nick> :Nickname is already in use`             | 이미 사용 중인 닉네임을 사용하려 할 때 발생합니다.     |
| 436       | `<nick> :Nickname collision KILL from <user>@<host>` | 닉네임 충돌로 인해 접속이 종료될 때 발생합니다.        |

## JOIN 커맨드

### 성공 메시지

| 번호 코드 | 메시지                                                                                          | 설명                                                     |
|-----------|-------------------------------------------------------------------------------------------------|----------------------------------------------------------|
| -         | `:<nick>!<user>@<host> JOIN <channel>`                                                          | 채널에 성공적으로 참여했을 때 표시됩니다.                 |
| 353       | `:<server> 353 <nick> = <channel> :<names>`                                                     | 채널의 현재 사용자 목록을 보여줍니다.                     |
| 366       | `:<server> 366 <nick> <channel> :End of /NAMES list`                                            | 사용자 목록의 끝을 알립니다.                              |
| 324       | `:<server> 324 <nick> <channel> +<modes> <mode params>`                                         | 채널의 현재 모드 설정을 보여줍니다.                       |

### 오류 메시지

| 번호 코드 | 메시지                                     | 오류 발생 이유                                        |
|-----------|--------------------------------------------|-------------------------------------------------------|
| 461       | `JOIN :Not enough parameters`              | 채널명을 제공하지 않았을 때 발생합니다.                |
| 474       | `<channel> :Cannot join channel (+b)`      | 채널에서 차단된 사용자가 참여를 시도할 때 발생합니다.  |
| 473       | `<channel> :Cannot join channel (+i)`      | 초대 전용 채널에 초대 없이 참여를 시도할 때 발생합니다.|
| 471       | `<channel> :Cannot join channel (+l)`      | 채널 인원이 가득 찼을 때 참여를 시도하면 발생합니다.   |
| 475       | `<channel> :Cannot join channel (+k)`      | 올바른 키(비밀번호)를 제공하지 않고 참여를 시도하면 발생합니다. |
| 403       | `<channel> :No such channel`               | 존재하지 않는 채널에 참여를 시도할 때 발생합니다.      |

| 319       | `<nick> :<channels>`                                                                     | 사용자가 참여하고 있는 채널 목록을 보여줍니다. |
