## 소켓 프로그래밍 맛보기

소켓 프로그래밍을 현실에 빗대어 표현하기

|현실|소켓|
|---|---|
|고객|클라이언트|
|회사|서버|
|대표번호 1577-1577|IP주소 192.121.42.42|
|내선 번호 101|포트 9000|
|고객이 회사 대표번호 1577-1577로 전화를 건 후 내선 번호 101에 연결 후 서비스를 요청한다.|클라이언트에서 서버에 요청을 하기위해 IP주소 192.121.42.42 포트번호 9000에 연결해 요청한다.|

## 서버의 통신 순서

|현실|함수명|동작|
|--|--|--|
|전화기 구매|r_socket = socket()|소켓 생성|
|전화기 번호 준비|typedef struct sockaddr_in|struct sockaddr_in addr;  addr.sin_port=htons(2000); 구조체 생성 후 포트번호 설정|
|전화선을 전화 케이블에 연결한다|bind(r_socket)|소켓을 포트에 연결|
|통신사에 전화기 개통 요청을 한다|listen(r_socket)|커널에 소켓 개통 요청|
|고객으로부터 요청이 오기를 기다림|while(true)|클라이언트 요청이 들어올때까지 기다림|
|고객으로부터 요청이 들어옴|accept()|클라이언트 연결 요청 수신|
|원래 있던 전화기(r_socket)는 듣기용으로 유지하고 서비스 제공을 위한 새로운 전화기(new_socket)를 생성한다|new_socket = accept(r_socket)|클라이언트의 접속 요청을 받아들이고, 연결된 새로운 소켓을 생성|
|고객의 서비스 요청을 수행함|read() & write()|클라이언트가 요청한 내용을 듣고 소켓에 쓰기|
|고객의 연결 종료|close(new_socket)|클라이언트와 연결 종료|
|서비스 종료|close(r_socket)|서버 프로세스 종료|

## 클라이언트의 통신 순서
|현실|함수명|동작|
|--|--|--|
|전화기 구매|c_socket = socket()|소켓 생성|
|서비스를 요청할 회사의 전화번호 준비하기|typedef struct sockaddr_in|연결할 서버의 주소 설정|
|전화로 회사에 전화를 걸고 서비스 요청|connect()|소켓을 서버에 연결|
|회사에 요청한 서비스 처리|read() & write()|서버로부터 받은 데이터를 버퍼에 담기|
|회사와 연결 종료|close(c_socket)|서버와 연결 종료|

## 서버
서버의 본질 = 프로세스
소켓의 본질 = 파일

프로세스가 파일에게 할 수 있는 것 = RWX (읽기/쓰기/실행)

파일을 읽는다 쓴다라는 개념이 소켓 통신에서는 다르게 쓰임.

* 읽기 = receive
* 쓰기 = send
